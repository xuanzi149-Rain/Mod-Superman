# 佩戴者任意武器附伤修复（2026-10-19）

用户需求：装备戒指后，自己的任意武器命中附加 1d4 火焰伤害，类似腐蚀指环；不开展 D 阶段。

## 根因及修复

原 trigger/on_hit 仅适用于承载被动的武器，校验要求 Weapon，生成条件为 AttackedWithPassiveSourceWeapon()。这是源武器效果，无法表达戒指赋予角色的任意武器附伤。不能单独删除武器限制。

本地原生记录 MAG_Acid_AcidDamageOnWeaponAttack_Ring_Passive 的 Boosts 为 CharacterWeaponDamage(2, Acid)。原生 Status_BOOST 中另有 CharacterWeaponDamage(1d4,Radiant) 等骰子用法。因此新增独立类型 weapon_damage，生成独立 PassiveData，Boosts=CharacterWeaponDamage(1d4,Fire)，挂入装备 PassivesOnEquip；不覆盖公共被动，不使用运行时脚本。装备期间作用于佩戴者的武器；不扩大到队友、徒手、纯法术、光环或附加条件。

新增类型适用现有合规 Weapon/Armor 装备模板，包括戒指、项链、护甲；修改和新建采用相同规则，创建仍需通过模板及获取入口校验。原生继承默认保留，因此添加效果并不代表替换原装备被动。原有武器参数及 source-weapon 命中限制保持不变。

## 解析和展示协议

新增操作示例：

```json
{"kind":"add_effect","target":"fire","payload":{"effect":{"kind":"weapon_damage","dice":"1d4","damage_type":"Fire"}}}
```

完整 envelope 例 E14 已加入 data/v1.1/task8/prompt-examples.json；相关任意武器/腐蚀指环输入优先选择该例。修改用 update_effect/effect_kind=weapon_damage，撤销用 remove_effect。骰子和伤害类型必填且受枚举/格式限制；无 duration_turns、target、状态标识。Prompt 明确区分此类型、基础伤害参数及当前武器命中效果，不要求玩家提供 ID。文案核对 facts 明确装备条件和作用范围。页面采用修改列表、确认页均展示该效果和骰子/伤害类型，并支持单项撤销与可选词条文案；未填词条使用 IsHidden，避免 Not Found。
