# 1.1 参考依据与采用方式

核对日期：2026-10-17。默认学习结构；没有复制第三方代码，也没有新增运行依赖。

| 需求 | 参考实现与固定版本 | 本地依据 | 采用方式及限制 |
|---|---|---|---|
| 独立装备、文本与文件组织 | [BG3 Forge authoring.py](https://github.com/crazyace/bg3-forge/blob/10fa2959b472bb71ba2714d274b9828e59cd4576/src/bg3forge/authoring.py)，MIT | equipment_catalog.py、generate_equipment.py、模板 LSX | 借鉴职责分离；Stats 与外观模板分别继承；仍用现有 LSLib。源码自称 experimental，不能替代本项目验收 |
| 被动执行与提示分开 | [Community Library 月光打击](https://github.com/BG3-Community-Library-Team/BG3-Community-Library/blob/adc881ef03780abae48df95a861e9061a406810e/CommunityLibrary/Public/CommunityLibrary/Stats/Generated/Data/CL_Class_Specific/NellsRelo_MarshmerrowMonk/Passives/CL_MartialArts_MoonlightStrike.txt)，MIT | 本地 Passive.txt 的 StatsFunctorContext、Conditions、StatsFunctors | 仅阅读范例。TooltipStatusApply 是展示，StatsFunctors 才定义执行；不复制该职业条件或引入库依赖 |
| 模板继承和外观 | [官方 Adding Armour](https://docs.baldursgate3.game/Adding_Armour)，访问日期版本 | 本地 RootTemplates/_merged.lsx | 继承现有外观，但种族/体型资源仍需校验；不根据 UUID 存在就开放创建 |
| 技能副本与单位 | [官方基础技能](https://docs.baldursgate3.game/Making_a_Basic_Spell)，访问日期版本 | Shared/Spell_Target.txt | TargetRadius 单位为米；执行、描述与动画分别处理。只借鉴思路，不复制教程资产 |
| 执行函数 | [官方 Functors](https://docs.baldursgate3.game/index.php?title=Functors)，访问日期版本 | Passive/Status/Spell 原始记录 | 后续建立白名单编译规则；不允许模型直接提交表达式 |

GitHub 提交号和 MIT 标识通过仓库 API 实时核对。官方网页没有固定提交号，按 URL 与核对日期记录；网页参考不等于授权复制游戏资源。

本地资源来源及 SHA-256 见 `data/v1.1/resource-summary.json`；完整索引由 `python -m scripts.resource_catalog_v11` 生成到 `build/v1.1/resource-catalog.json`，不将大体积原始游戏索引提交到 Git。已有提取数据的游戏补丁版本尚未建立证明链，不能把当前 Steam buildid 反推为旧提取文件版本。
