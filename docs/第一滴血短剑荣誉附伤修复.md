## 原因与依据

旧版完整记录来自 Gustav，显式写入 DefaultBoosts=WeaponProperty(Magical)，没有保留 Honour 的同名装备覆盖。荣誉规则中的装备原始字段为：

```text
WeaponProperty(Magical);IF(HasMaxHPWithoutTemporaryHP(context.Target)):WeaponDamage(1d8, Piercing)
```

与此同时 Honour 的 UND_Duergar_ShortswordOfFirstBlood_Passive 将 StatsFunctorContext、Conditions、StatsFunctors 设为空，附伤不再由普通版的 OnAttack 被动执行。旧包覆盖掉装备上的条件 WeaponDamage 后，两条实现路径都不能提供满血附伤。

原始记录保存在 samples/first-blood/mode-source，来自本地 Gustav.pak 的 Public/Gustav 和 Public/Honour Stats。对照证据为 evidence/first-blood/10-v1-enabled-no-full-hp-bonus.png 与 11-disabled-full-hp-bonus.png。

此前只将输出与普通版本手工模板比较，能够证明复现，但没有覆盖难度规则差异。以后对象验证需要记录规则集，并核对后加载的同名记录；不能仅凭普通版字段未变化就断言其他规则不受影响。

## v2 修改

使用游戏 Honour 自身采用的同名继承写法，仅覆盖一项伤害：

```text
new entry "UND_Duergar_ShortswordOfFirstBlood"
type "Weapon"
using "UND_Duergar_ShortswordOfFirstBlood"
data "Damage" "2d6"
```

不显式写入 DefaultBoosts、PassivesOnEquip、普通短剑父记录或其他装备属性，保留游戏当前规则的数据。模组 UUID 保持 fa86e11f-65e1-7489-881e-69cb2b80e055，Version64 升为 36028797018963971，不同时启用新旧模块。

生成脚本为 scripts/generate_first_blood_v2.py。旧 scripts/generate_first_blood.py 和 before/after 只保留为 v1 复现历史材料；后续不要再把旧版 Toolkit 项目发布包覆盖回安装目录，否则会恢复已发现问题。
