## 实现与配置

沿用httpx和OpenAI兼容Chat Completions协议，不增加SDK或框架。输入仍为当前对象字段、原值、有效草稿、必要历史和用户需求；模型输出仍经Pydantic与目录规则校验，再由用户独立确认。切换供应商不改变文件生成权限。

`.env.local`配置项：

```dotenv
MODEL_PROVIDER=bailian
MODEL_NAME=qwen3.7-plus
MODEL_BASE_URL=https://token-plan.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
MODEL_USE_SYSTEM_PROXY=0
BAILIAN_TOKEN_PLAN_API_KEY=
```

用户在本地补齐最后一项，不将密钥写入聊天、前端或提交Git。Token Plan专用端点只读取其专用密钥，不复用DeepSeek或普通DashScope密钥。普通百炼按量端点读取DASHSCOPE_API_KEY。密钥必须与端点地域和账户权限匹配。

请求地址为Base URL拼接/chat/completions；百炼使用enable_thinking=false，DeepSeek兼容分支保留thinking.type=disabled。保持stream=false、JSON对象输出、2500最大输出token、10秒连接等待和65秒总等待。网页得到完整并通过校验的结果后才能预览，不把HTTP200作为解析成功。

API地址只允许所选供应商的官方HTTPS域名及已知兼容路径，不接受含用户名、查询参数或非标准端口的地址；避免修改配置时把旧供应商密钥发送到错误地址。没有百炼密钥时明确提示未配置，不自动回退到故障中的DeepSeek。

服务端环境变量优先于.env.local；每次真实请求重新读取配置。代码更新需重启服务；只修改配置或密钥无需重启。当前本地服务入口仍为http://127.0.0.1:8016/ 。

AI历史、阶段诊断和评测报告增加provider和model区分，避免将以前DeepSeek的16/16、8/8结果算到新模型。已完成接入兼容检查和一次真实完整自动验收；新供应商解析质量仍需整套真实评测，不能用单次结果推断总体通过率。
