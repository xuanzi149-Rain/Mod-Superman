# 第一滴血短剑附伤和停用补测

Python 程序包的基础伤害修改已由用户确认生效。本次补测保留满血附伤、普通短剑不受影响和停用恢复三项行为，并补充一次受伤目标的普通攻击日志。测试结果填写到《第一滴血短剑验证记录.md》，不用重新修改或打包。

## 准备测试条件

1. 使用测试存档，保留一份启用测试包之前的原存档，不覆盖主存档。启用 FirstBloodDamageTest，记录其他启用 Mod。
2. 使用主手第一滴血短剑，暂时卸下造成额外伤害的装备，取消涂毒或浸蘸效果。选择普通主手近战攻击，关闭自动偷袭等额外伤害反应。
3. 选择测试档中能够承受两次攻击、没有穿刺抗性或易伤的敌人。攻击前截图显示其当前血量等于最大血量。不要用必定暴击或必定使敌人易伤的条件。
4. 记录角色属性加值和可能无法取消的重掷效果。它们不妨碍核对骰公式，但不能将最终总伤害直接当作基础伤害。

## 满血与受伤目标对照

5. 对满血目标进行一次命中的非暴击普通攻击，展开或悬停战斗日志的伤害详情，保存包含完整组成的截图。
6. 预期基础项使用 2d6，角色属性加值维持原规则，专属满血附伤仍为 1d8。日志可能分行或合并显示；如无法分辨，提供完整详情后再核对，不凭总数字判断。
7. 保持装备和攻击方式不变，对同一个已经受伤的目标再进行一次命中的非暴击普通攻击，保存伤害详情。预期基础仍是 2d6，不再触发满血附伤；不要误把其他来源的附伤判为专属效果。
8. 如果首次攻击杀死目标，重新载入测试副本并选择血量更高的目标。未命中或暴击不能代替这次对照。

## 普通短剑与停用恢复

9. 保持 Mod 启用，装备一把普通无附魔短剑。记录其准确名称，查看说明中的基础骰是否仍为 1d6；没有这类装备则记为待补测，不用特殊短剑替代。
10. 回到主菜单，在 Mod 管理器中停用 FirstBloodDamageTest，退出桌面并重新启动。加载原测试档；若出现 Mod 验证窗口，确认测试 Mod 不被重新勾选启用。不要保存覆盖原档。
11. 重新装备第一滴血短剑，查看基础伤害恢复为 1d6，并保存物品详情截图。属性加值和其他来源附伤可能仍显示，核对基础骰即可。
12. 测试后重新启用测试 Mod，退出桌面并重新启动，再加载测试副本，确认恢复为 2d6。此步用于确认可重复启用。

## 返回结果

一次提交以下结果和证据：满血目标基础骰与附伤、受伤目标基础骰与附伤、普通短剑基础骰、停用与重新启用后的基础骰。区分截图已观察、用户口头确认和未完成，不要求重复已经保存过的文件。
