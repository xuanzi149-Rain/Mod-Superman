## 整体实现

目录查询 → 参数校验并保存预览 → 用户确认方案编号 → 后端读取相同参数、重新校验版本 → 生成最小修改文件并检查结构与修改范围 → LSLib 打包并解包逐文件比较 → ZIP 内容核对 → 下载。

采用 FastAPI、Pydantic、现有 Python 生成器及 LSLib，不调用模型。目录字段和输入限制来自生成器共用规则；接口不接受用户填写 Stats 标识、名称句柄、文件路径或原始文件代码。候选目录不等于全量游戏已验证。

预览以 JSON 保存。生成接口只接收确认和试验确认，不接收参数变更。修改参数须创建新预览并确认其编号；旧编号仅对应旧参数。目录、生成器或模板摘要变化后，旧预览拒绝生成。相同成功方案重复提交返回同一结果；失败或中断需要新预览重试。

## HTTP 接口

| 方法与路径 | 输入 | 输出 |
|---|---|---|
| GET /api/equipment | search、category、offset、limit（1～100） | 匹配总数、分页候选、能力与历史验证标签 |
| GET /api/equipment/{object_id} | 目录对象 ID | 原值、字段规则、禁用原因、共用与继承范围 |
| POST /api/previews | object、changes | 保存的标准化参数、方案编号、原值/新值、警告和版本摘要 |
| POST /api/plans/{plan_id}/generate | confirmed、accept_experimental | 生成状态、分阶段检查结果、成功下载地址 |
| GET /api/plans/{plan_id} | 方案编号 | 预览或制作状态；工具原始错误保留在本地诊断文件 |
| GET /api/plans/{plan_id}/download | 方案编号 | 仅成功且摘要未变的 ZIP |

422 表示请求结构或参数无效；404 表示对象或方案不存在；409 表示未确认、未接受试验、版本变化或状态不允许；500 表示生成、打包、ZIP 或下载完整性失败。错误返回 detail，业务错误含 code 和 message；Pydantic 结构错误含字段位置。

未知字段、多余顶层字段、重复 JSON 键、NaN/Infinity、错误类型、空修改和越界值被拒绝。试验确认仅允许合法未验证方案，不能绕过校验。

当前生成器只识别第一滴血 2d6 和曙光短剑单字段为已有方案；其他已有用户报告暂保留在历史反馈资料，接口保守提示试验，未自动升级整个对象或范围。

## 完整例子

先通过目录选择第一滴血短剑，然后 POST /api/previews：

```json
{
  "object": "equipment:1e172d76-3433-4ee7-ae1a-9e7d8ae0f12b",
  "changes": {"damage": "2d6"}
}
```

预览展示原值 1d6、新值 2d6、影响范围和本次游戏未验证。读取返回的 plan_id，POST 对应 generate 接口：

```json
{"confirmed": true, "accept_experimental": false}
```

源文件仅覆盖 Damage，保留同名继承，不复制 DefaultBoosts、被动或 RootTemplate。PAK 解包核对成功后，ZIP 包含 PAK、修改清单.json 和使用说明.txt。下载地址由响应的 download_url 提供。输入参数变化必须先重新创建预览。

使用说明由固定程序模板生成，列明安装、停用、影响范围、游戏版本依据与未验证限制。程序不自动安装、不更改存档或游戏启用配置。

## 状态、产物与限制

制作记录位于 build/backend/plans，PAK、源文件、解包对照及 result.json 位于 packages，ZIP 位于 downloads。清单保存确认参数、目录与模板/代码摘要、原值、作用范围、包摘要及阶段状态。真实打包检查汇总位于 build/backend/verification.json。

分别记录源文件检查、PAK 创建、包内容检查、ZIP 检查和游戏验证；失败不会返回可用下载地址。新生成包不继承历史游戏通过结论。

当前为本地单进程同步生成，用锁防止重复提交并保护状态写入；进程中断保留 generating 状态，需新预览恢复。尚未实现公开部署、账户、请求限额、任务队列、跨进程协调或反馈数据库，这些按部分 5 的交付范围推进。公开服务前还需确定产物清理策略与打包工具部署环境。

## 本轮验收

原有 40 项测试加本轮 12 项，共 52 项通过（最终全量回归耗时 2.053 秒）。覆盖对象与字段限制、严格类型、重复键、确认及试验门槛、版本变化、参数夹带、重复提交、状态持久化、失败无下载、下载摘要损坏、输出修改范围及中文 XML 转义。

真实接口打包两份方案：第一滴血基础伤害 2d6；第一滴血名称含 XML 特殊字符、重量 1.125 kg、稀有度 Rare 的试验组合。生成、PAK 创建、解包逐文件核对和 ZIP 内容核对通过；两份新包均未游戏验证。接口验收由 TestClient 完成，另通过本机 HTTP 启动冒烟检查验证服务器入口。

最终两份制作编号分别为 `334ff147-38fd-4245-b865-0538f7318aee` 和 `9de495ca-b64e-40c1-9723-0c5e9e3cc0db`，对应 ZIP 位于 build/backend/downloads。HTTP 冒烟检查通过目录与 OpenAPI 请求，目录返回 1,872 个候选；临时服务器检查后已停止。证据见 build/backend/verification.json、http-verification.json 和 http-smoke.log。

## 阶段讲解与求职证据

用户确定装备范围、排除治愈真言并接受试验与 PAK ZIP 交付；智能体完成接口、持久化预览和确认、生成结构检查、ZIP 交付、测试与说明。

Python 模块封装使现有生成器可被 HTTP 复用；Pydantic 与目录规则拦截错误请求；结构化 JSON 保存可复现方案；FastAPI 提供目录、预览、生成和下载 API；自动化检查验证确认门槛、文件修改范围和失败恢复。这些均对应实际代码与检查产物，不记录未测量的通过率或效率改善指标。
