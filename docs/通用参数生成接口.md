# 已支持对象的参数化生成与打包接口

2026-10-13 已实现 scripts/generate_mod.py，提供 JSON 命令行入口和可导入的 generate 函数。生成和打包不调用模型 API。当前支持第一滴血短剑与治愈真言，每次请求只修改一个对象，可包含多个已开放字段；不是任意游戏对象编辑器，也没有实现 HTTP 服务。

## 开放输入

| 对象 | 字段 | 类型与本轮输入限制 | 已有游戏成功值 |
|---|---|---|---|
| 第一滴血短剑 | damage | 伤害骰字符串，例如 3d6；骰数量 1～10，骰面限 4、6、8、10、12、20，不支持固定加值或任意表达式 | 2d6 |
| 第一滴血短剑 | dexterity_bonus | 装备敏捷加成，整数 1～4 | 2 |
| 第一滴血短剑 | name | 1～60 个字符，排除控制字符和非法 XML 字符；仅简体中文 | 曙光短剑 |
| 第一滴血短剑 | passive_mode | keep 或 replace_with_alert；后者移除满血附伤并替换为警觉 | 原效果保留路径、警觉替换路径 |
| 治愈真言 | cast_distance_m | 1～60 米，整数或至多一位小数 | 36 |

上述范围是保守的产品输入限制，不是已测出的游戏引擎极限。只有右列方案有此前用户游戏确认；其他数值、名称及多个游戏字段的组合是试验方案。name 与单一玩法字段的组合可按此前改名加属性路径处理；多个玩法字段组合必须明确作为试验。范围半径、其他角色属性、描述改写、治疗量、任意被动 ID 均未开放。

未知对象、未知字段、额外请求字段、空修改、无效类型、非有限数、越界值和重复 JSON 键直接拒绝；试验模式也不能绕过这些规则。未知数值或组合没有 --experimental 时拒绝生成。--confirmed 是参数确认标记；用户之后改变参数，需要按新参数重新确认生成。

## 输入与使用

请求必须只有 object 和 changes。完整示例：

```json
{
  "object": "first_blood_shortsword",
  "changes": {
    "name": "晨光短剑",
    "damage": "3d6",
    "dexterity_bonus": 3,
    "passive_mode": "replace_with_alert"
  }
}
```

示例文件为 requests/equipment-combined-experimental.json。既有方案示例为 requests/first-blood-damage.json 和 requests/healing-word-distance.json。在项目根目录执行：

```powershell
& 'C:\Users\17583\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts/generate_mod.py --request requests/equipment-combined-experimental.json --confirmed --experimental
```

查看输入目录与规则：

```powershell
& 'C:\Users\17583\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts/generate_mod.py --catalog
```

接口函数：generate(request, output_root, confirmed=True, allow_unverified=False, packager=DIVINE)，返回实际 .pak 的 Path。调用方传结构化字典并处理 ValidationError、打包错误等；暂不提供自然语言解析。聊天中助手可以整理参数，但脚本本身接受 JSON，文件生成与打包不会请求任何模型服务。

每次成功生成使用新的模块 UUID，目录为 build/generated-mods/UUID，包含 .pak、mod-source、解包对照、result.json 和使用说明。生成过程不修改已安装 Mod、存档或游戏启用配置。输出清单分别记录文件生成、打包、包检查和未执行的游戏验证；发生打包错误保留失败记录，不返回成功下载结果。

LSLib 工具默认放在 .tools/lslib/v1.20.4/Packed/Tools/Divine.exe，可通过 --packager 指定已有工具位置。没有引入新 Python 依赖。

## 修改规则与组合

短剑使用同名继承，只有请求的字段才写入。只改 Damage 不会写 DefaultBoosts；添加敏捷保留原被动及荣誉附伤。replace_with_alert 是用户明确要求替换，因此同时移除原被动引用和荣誉条件伤害。

敏捷加成与警觉替换组合时，生成一个被动列表 Alert;本次敏捷被动，避免独立测试包之间相互覆盖。属性被动和文本句柄带本次 UUID，不与其他请求共用。新增包不声明能与同一对象的其他 Mod 任意兼容；游戏验收时停用原测试包及旧生成包，避免加载顺序影响。

治愈真言依据已校验的真实基础模板，仅替换 TargetRadius，治疗、消耗、动画等其他内容保留。二至六级仍可能继承该距离，不声称均已游戏测试。名称仅覆盖原装备的简体中文名称句柄，不创建新装备。
