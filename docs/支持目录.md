三个测试包：名称改为曙光短剑、装备后敏捷 +2、移除满血附伤并替换为警觉。原始数据核对、21 项检查、打包与解包及安装摘要检查通过；用户确认三项均实测成功，主要效果记为用户报告通过，详细子项与截图仍待补齐。独立敏捷和警觉测试包互斥，改名包仅支持简体中文。详见《装备名称属性被动验证.md》。

## 参数化生成入口

scripts/generate_mod.py 已接收 JSON 参数并直接调用本地 LSLib 返回 .pak。支持两对象及 damage、dexterity_bonus、name、passive_mode、cast_distance_m 五字段。新数值和多玩法组合需要显式试验生成，不能等同于整个数值范围已游戏通过。输入限制、调用方式与三份真实打包检查见《通用参数生成接口.md》。网站 HTTP 接口尚未实现。
