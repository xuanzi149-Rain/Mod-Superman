Mod-Superman：补充界面与状态的手动导入指南

一、文件与使用方式
本包包含20份SVG。04-结果下载页是完整1440×1000页面；状态文件是880×590的正文片段；弹窗是独立画框；首页补丁-技能输入仅替换首页输入区。
沿用红、黄、黑、白，文字指定Noto Sans SC Regular/Medium且没有文字描边。BG3标志使用用户提供的金色图片，属于现有标志资产。
PNG仅用于查看效果；导入SVG才能得到可编辑图层。所有文件已带白色背景。
SVG不包含点击连接、自由输入、真实API或下载功能。文件中的预设值用于演示。

二、先导入并整理（不替换现有前三页）
1. 解压补充设计稿.zip。
2. 在Figma打开你已编辑的“问答视觉V3”页面，保持编辑模式。
3. 从解压目录将SVG拖到空白画布。不要放进现有画框中。
4. 完整下载页放在第三页旁边；弹窗放在主页面上方；状态片段放在下方备用。
5. 把最外层画框改名为文件名，删除自动追加的“1”等后缀可使连接表更容易对应。
6. 点击文字检查字体。若显示Inter，改为Noto Sans SC；若出现Stroke描边，去除。不要给文字增加描边。
7. 下载页logo若导入不显示，拖入design/assets/bg3-logo-clear-transparent-2x.png，锁定宽高比，宽150，顶部居中。
8. 对新下载页使用自己前三页的标题和标志位置作为对齐参照；仅调整页头，保持下载信息区域完整。

三、先补齐正常主线
选中第三页“生成修改文件”红色按钮背景，右侧Prototype。拖出蓝色连接点至04-结果下载页。
On click → Navigate to → 04-结果下载页 → Instant。
选中04右上角“新的修改”外框，连接回现有首页。
不要将On click挂在整页画框上。
如SVG中按钮背景和文字分开，按Ctrl分别选中背景，或Shift选择背景和文字后Ctrl+G组成按钮组，再对这个组添加交互。确保点击热区覆盖整个按钮。

四、弹窗怎么连接
首页黄色对象标签 → On click → Open overlay → 弹窗-A-装备选择。
Position选择Centered/居中；先不勾选Add background，以保留当前配色。勾选Close when clicking outside/点击外部关闭。
弹窗里的右上角×、取消或知道了 → On click → Close overlay。关闭动作不需要指定页面。
A里的“技能”标签 → On click → Swap overlay → 弹窗-B-技能选择；B里的“装备”标签 → Swap overlay → A。
A里的“选择第一滴血短剑” → Close overlay（当前首页已是该对象）。
C是搜索无结果的另一个弹窗状态，独立播放测试，不把它强行接到正常搜索。输入只是静态示例，不模拟真正自由搜索。
04的“安装与验证说明” → Open overlay → 弹窗-D-安装与验证说明。
04的“遇到问题” → Open overlay → 弹窗-E-问题反馈。
E的“提交反馈” → Swap overlay → 弹窗-F-反馈完成；F的“返回制作结果” → Close overlay。
04的“成功使用” → Open overlay → F；此处演示反馈完成，不声称实际提交。
04的“下载修改文件” → Open overlay → 弹窗-G-下载预览，G的“返回制作结果” → Close overlay。
H是下载失败状态。独立测试时打开H，点击重试下载 → Swap overlay → G。
问题反馈目前预选安装阶段。若要测试不同阶段：复制E，分别将对应胶囊背景改为黄色，其余改白色黑边，连接时用Swap overlay切换这些副本；预填说明也一并修改。不需要新增前端管理页。

五、如何在前三页添加“正文状态”
保持原前三页不动，先复制页面作为状态副本。
示例：制作第二页澄清状态。
1. 在Layers点击第二页最外层画框名称，Ctrl+D复制，改名“02-需要澄清”。
2. 展开副本图层，选中问答正文的图层（提问气泡、答案、参数行、影响范围、按钮、底部输入框）。按Shift多选后Ctrl+G，改名“原正文”。保留顶部导航、logo和页面标题。
3. 关闭“原正文”的眼睛图标，隐藏旧内容。若原文分散在多个图层，先多选分组再隐藏，不要隐藏页头。
4. 在空白画布选中“状态-02-需要澄清”最外层画框，Ctrl+C。
5. 在Layers选中“02-需要澄清”最外层画框，Ctrl+V，使片段成为它的子图层。
6. 看左侧层级：状态片段应缩进在副本内。若仍是顶层，拖动图层名称到副本下。
7. 选中贴入的片段，在右侧Design设置X=280、Y=270、W=880、H=590（此坐标以1440×1000页面为基准）。可按自己的标题高度略调Y；三页内相同位置尽量统一。
8. 如副本存在Auto layout而无法输入X/Y，先确认没有误选内容。确为自动布局时，可按Shift+Alt+A移除副本的自动布局，再按绝对位置放置；原页面不受影响。不要改动原有画框。
9. 播放副本，确认旧正文没有漏出、新正文没有遮住logo或标题。
10. 从这个状态的按钮背景开始添加跳转，不要沿用复制页旧正文中的交互。
对解析失败、编辑、参数无效、生成中/失败重复上述方法。首页解析状态也可复制首页保留页头，将大口号、原输入区、建议和底部步骤统一隐藏，替换为问答正文状态；不必重新复制或设计logo。

六、建议建立的页面副本与连接
01-解析中：复制首页并贴“状态-01-解析中”。选整个副本画框，Prototype添加After delay=800ms → Navigate to → 第二页；“返回修改输入”→首页。
01-解析失败：复制首页并贴同名状态。“重试解析”→01-解析中，“直接填写参数”→02-参数编辑（预设示例路径）。
01-不支持需求：复制首页并贴同名状态，“调整修改需求”→首页。
02-需要澄清：复制第二页并贴同名状态。“基础伤害骰翻倍”→原第二页，“重新描述”→首页。
02-参数编辑：复制第二页并贴同名状态；本示例值3d6。“取消修改”→原第二页。
02-参数无效：复制第二页并贴同名状态；本示例20d6。“修正为2d6”→原第二页，“取消修改”→原第二页。
03-生成中：复制第三页并贴同名状态。After delay=1000ms → Navigate to → 04；无点击提交按钮，避免重复生成。
03-生成失败：复制第三页并贴同名状态。“重试生成”→03-生成中，“返回参数”→原第二页。
将原首页发送按钮改连01-解析中；将原第三页生成按钮改连03-生成中。
将原第二页“继续调整”改连02-参数编辑；原第三页“继续调整”也回02-参数编辑。

注意：编辑为3d6的支线不能直接跳到仍显示2d6的第三页。
复制你现有第三页为“03-确认3d6”，把需求气泡、说明与目标值同步改为3d6；复制04为“04-结果3d6”，将修改摘要改为1d6→3d6。
02-参数编辑的“重新确认参数”→03-确认3d6；03-确认3d6的生成按钮→04-结果3d6；04-结果3d6的新的修改→首页。
若要给此支线添加加载状态，再复制03-生成中并把2d6文案改为3d6、延时目标改到04-结果3d6。
副本中不要继承指向2d6结果的旧连接。反馈也要对应制作编号和参数，不能把两个方案混在一起。

七、技能示例路径（在装备主线之后完成）
复制首页为“01-治愈真言”。隐藏原输入区，将“首页补丁-技能输入”贴入，设置X=280、Y=418；保持自己已优化的标题、标志和其他结构。
B里的“选择治愈真言”→Navigate to→01-治愈真言（不是Close overlay，否则首页仍显示短剑）。
复制第二页为“02-技能结果”，正文替换“状态-技能-结果”。复制第三页为“03-技能确认”，正文替换“状态-技能-确认”。
技能首页发送→02-技能结果；确认参数→03-技能确认。
复制04为“04-技能下载”，把对象改为治愈真言、摘要改为18→36米；03-技能确认的生成按钮连到该页。
技能“继续调整”可先返回技能首页重新描述；如做直接参数编辑，则复制技能结果页做编辑状态，不能跳到短剑参数页。

八、错误状态如何测试
不要在正式首页放“演示失败”按钮。
在编辑画布选中01-解析失败、01-不支持需求、02-参数无效、03-生成失败等状态副本，右侧Prototype中的Flow starting point点+，按状态命名测试流程。
测试加载成功时可以自动跳转；测试失败时从失败起点进入。当前静态原型不能根据自由文本自动决定成败。
搜索无结果和下载失败是独立弹窗，需有宿主页才能播放。复制首页或04作为测试宿主页，分别让黄色对象标签打开C、下载按钮打开H，并给宿主页设置测试起点。无需改正式主流程。

九、最终检查
点击空白处不应整页跳转。
对象选择可取消，弹窗切换与关闭正常。
发送→解析中→结果→确认→生成中→下载页完整。
参数变更后重新确认，3d6支线不可出现2d6结果。
模型失败、参数无效、不支持和生成失败均有恢复入口。
下载页能查看本地说明、模拟下载及反馈。
技能和装备的文案、值与结果不能混用。
字体显示完整，没有文字描边；logo未丢失。
文件/生成/游戏状态分开，不把原型演示当作实际完成。
